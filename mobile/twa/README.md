# AllotMint Trusted Web Activity

The Android shell that publishes the PWA on Google Play (#11036). Setup,
signing and release steps are in
[`docs/ANDROID_PLAY_STORE.md`](../../docs/ANDROID_PLAY_STORE.md).

This project was generated by Bubblewrap (`@bubblewrap/core` 1.27.0) from
`frontend/public/manifest.webmanifest`. `twa-manifest.json` is its source of
truth. If you regenerate it (e.g. `npx @bubblewrap/cli update`), re-apply
these hand edits, because the generator overwrites them:

- **`app/build.gradle`**: the release `signingConfigs` block and the
  `versionCode`/`versionName` lines read `TWA_KEYSTORE_PATH`,
  `TWA_KEYSTORE_PASSWORD`, `TWA_KEY_ALIAS`, `TWA_KEY_PASSWORD`,
  `TWA_VERSION_CODE` and `TWA_VERSION_NAME` from the environment. With no
  keystore set, release builds are unsigned.
- **`build.gradle`**: `mavenCentral()` instead of the generated `jcenter()`
  (JCenter is sunset).
- **`minSdkVersion` 24**: Bubblewrap 1.27 defaults to 21, but the
  `androidbrowserhelper` 2.7.4 it pins requires 24, so the default fails the
  manifest merge. This is set in `twa-manifest.json`, so regeneration keeps it.
- **Gradle wrapper**: regenerated as the official 8.11.1 wrapper (Bubblewrap
  shipped a Gradle 5.x wrapper JAR), with `distributionSha256Sum` pinned in
  `gradle/wrapper/gradle-wrapper.properties`.

Local build (JDK 17+ and the Android SDK; `ANDROID_HOME` set or
`local.properties` with `sdk.dir=...`):

```bash
./gradlew bundleRelease          # unsigned
TWA_KEYSTORE_PATH=/path/to/allotmint-upload.jks TWA_KEYSTORE_PASSWORD=... \
  TWA_KEY_PASSWORD=... TWA_VERSION_CODE=1 ./gradlew bundleRelease   # signed
```

The output is `app/build/outputs/bundle/release/app-release.aab`.
