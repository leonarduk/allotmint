# One entry per unwrapped call, keyed on line-independent call identity
# (#8689), not file:line:
#
#     <path>::<enclosing class/function qualname or <module>>::<call source>
#
# <call source> is the whitespace-collapsed ast.unparse() of the call, so
# re-indenting or re-wrapping a call, or editing other lines in the file,
# does not change its key. Editing the call itself (its arguments, message,
# or moving it to another function) does. Identical calls in the same scope
# share a key: list it once per occurrence.
#
# Keep entries sorted. Lines starting with # are comments; put a comment
# above any new entry explaining why its value can't carry
# attacker-controlled input. Print the current findings in this format with:
#
#     python scripts/build_tools/_scan_log_sanitisation.py
